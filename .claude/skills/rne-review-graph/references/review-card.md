# 공통 검토 카드 — 관문 기준

관문 노드(rne-gate)가 **심사 결과물의 품질**을 판정하는 기준입니다.
학생 제안서를 다시 채점하는 것이 아니라, 교과·운영·협의회 노드가 낸 결과가
"결재에 올리고 학생에게 전해도 되는 수준인가"를 봅니다.

> 영재교육부 2학기 파일럿의 실제 공통 검토 카드 항목이 정해지면 이 파일을 그 내용으로 바꾸세요.
> 항목 ID(G1, G2 …)와 등급(A·B·C) 표기만 유지하면 스크립트는 그대로 동작합니다.

## 산출물 등급

| 등급 | 뜻 | 관문 결과 |
|---|---|---|
| A | 결재 후 학생에게 그대로 전해도 되는 수준 | pass |
| B | 결재자가 한 번 읽고 표현을 다듬으면 되는 수준 | pass |
| C | 빠진 것·틀린 것이 있어 해당 노드가 다시 써야 함 | revise |

## 검토 항목

| ID | 항목 | 통과 조건 |
|---|---|---|
| G1 | 빠진 검토 없음 | 분야 판별이 고른 모든 교과와 운영이 결과를 냈고, 플래그마다 담당 노드가 판단을 적었다 |
| G2 | 근거 | 모든 필수 수정(must_fix)에 제안서 근거(evidence)가 있고, 근거가 실제 제안서 내용과 맞는다 |
| G3 | 사실성 | 제안서에 없는 내용을 사실처럼 단정하지 않았다 (추정은 추정이라고 밝힘) |
| G4 | 실행 가능성 | 모든 필수 수정에 학생이 따라 할 수 있는 수정 방향(suggestion)이 있다 |
| G5 | 안전·윤리 | 안전·윤리 판단이 플래그와 맞고, "심의 필요"라면 필요한 절차가 적혀 있다 |
| G6 | 예산·일정 | 운영 노드가 예산과 일정을 운영 기준의 숫자로 판단했다 |
| G7 | 일관성 | 교과 판정과 협의회 권고가 서로 맞거나, 어긋나는 이유가 협의회에 설명돼 있다 |
| G8 | 전달 가능성 | 학생에게 옮길 수 있는 표현이다 (비난조·과도한 전문용어 없음) |

## 판정 규칙

- G1~G7이 모두 충족되면 **pass**. 이때 G8이 충족되면 A, 아니면 B.
- G1~G7 중 하나라도 어긋나면 **revise**, 등급 C.
  - 고칠 노드를 `revise`에 적는다. 교과·운영 결과가 바뀌어야 하면 그 노드를, 종합만 틀렸으면 `council`을 지정한다.
  - 지시문은 행동으로 적는다: "무엇이 빠졌다 → 무엇을 추가하라".
- 확실하지 않은 문제, 표현 취향 문제로는 revise하지 않는다.
- 관문은 한 주기에 최대 3번(첫 판정 + 재검토 2번)까지 돈다. 그래도 C면 "미해결"로 결재에 올라간다.
