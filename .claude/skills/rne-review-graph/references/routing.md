# 분야 판별 규칙

분야 판별 노드(rne-router)가 어느 교과 에이전트에게 제안서를 보낼지 정하는 기준입니다.
부서 사정에 맞게 고쳐 써도 됩니다. 분야 코드(math 등)만 바꾸지 않으면 스크립트가 그대로 동작합니다.

## 분야 코드와 연결된 스킬

| 코드 | 교과 | 검토 에이전트 | 쓰는 스킬 |
|---|---|---|---|
| math | 수학 | rne-review-math | math-rne-agent |
| physics | 물리 | rne-review-physics | physics-rne-agent |
| chemistry | 화학 | rne-review-chemistry | chemistry-rne-agent |
| biology | 생명과학 | rne-review-biology | biology-rne-agent |
| earth | 지구과학 | rne-review-earth | earth-science-rne-agent |
| cs | 정보·AI | rne-review-cs | cs-rne-agent |

운영(rne-review-ops, rne-operations-agent)은 분야와 상관없이 **항상** 함께 검토하므로 여기서 고르지 않습니다.

## 고르는 순서

1. **주 분야 1개** — 연구 질문 자체가 속한 교과. 제안서의 "연구 분야" 칸보다 실제 연구 질문을 우선한다.
2. **안전·윤리 담당** — 아래 플래그가 있으면 해당 교과를 넣는다.
   - 인간대상, 동물, 생물시료 → biology (생명윤리 심의 판단)
   - 화학물질 → chemistry (MSDS·폐액·보호구 판단)
3. **방법론 보조 분야** — 연구의 핵심 방법이 다른 교과의 전문성을 요구할 때만 넣는다.
   - 머신러닝 모델 학습·평가, 대규모 코드, 데이터 수집 자동화 → cs
   - 증명, 수리 모형의 해석, 통계 모형 설계가 결과를 좌우 → math
   - 합성·정량 분석·기기 분석 → chemistry
   - 공개 기상·해양·지질·천문 데이터, 야외 관측 → earth
   - 측정 장비 설계, 역학·광학·전자기 실험 → physics
4. **최대 3개** — 넘치면 비중이 큰 순서로 3개만 두고, 뺀 분야는 reason에 적는다.
   우선순위: 주 분야 > 안전·윤리 담당 > 방법론 보조 분야.

## 넣지 않는 경우

- 도구로만 쓰는 경우: 엑셀로 그래프 그리기, 파이썬으로 평균 내기, 스마트폰 앱으로 값 읽기.
- 동기나 배경에만 등장하는 분야.

## 플래그 (해당하는 것 모두)

| 플래그 | 이럴 때 |
|---|---|
| 화학물질 | 시약, 용매, 산·염기, 가열 반응, 폐액이 생김 |
| 생물시료 | 미생물·세포·식물·조직·혈액 등 생물 재료 |
| 인간대상 | 설문, 인터뷰, 사람의 신체 측정·행동 관찰 |
| 동물 | 척추동물 실험·관찰 |
| 고위험장비 | 고전압, 레이저, 방사선, 고온·고압, 회전체 |
| 야외·야간활동 | 현장 조사, 채집, 야간 천체 관측 |
| 데이터라이선스 | 외부 데이터셋·웹 수집·타인 저작물 사용 |
| 생성AI활용 | 생성형 AI로 코드·글·분석을 돕게 함 |
| 고가장비구입 | 태블릿·노트북·고가 센서 등 개별 고가 물품 구입 계획 |
