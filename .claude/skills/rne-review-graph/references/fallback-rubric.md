# 대체 검토 기준 (교과 스킬을 불러오지 못했을 때)

교과 노드는 원래 미리 불러온 교과 스킬(physics-rne-agent 등)의 기준을 따릅니다.
스킬이 설치되지 않았거나 이름이 달라 내용이 보이지 않으면 이 기준으로 검토하고,
결과 JSON의 `skill_used`에 `"fallback"`이라고 적습니다. 오케스트레이터는 이를 결재 요약에 드러냅니다.

## 주제 심사 체크리스트

- [ ] 연구 질문이 한 문장으로 분명한가 (무엇을, 왜, 어떻게)
- [ ] 고교 실험실·학교 장비·주어진 기간 안에서 할 수 있는가
- [ ] 측정·관찰할 양과 방법이 정해져 있는가 (장비, 정밀도, 반복 횟수)
- [ ] 독립·종속·통제 변인이 구분돼 있는가
- [ ] 결과를 판단할 기준(대조군, 비교 대상, 통계 방법)이 있는가
- [ ] 선행 연구를 확인했는가 (블로그만이 아닌 교과서·논문·공식 자료)
- [ ] 안전·윤리 위험이 있는가, 있다면 대비책이 있는가
- [ ] 예상 결과가 가설로 적혀 있고, 틀릴 수도 있는 형태인가

## 결과 문서 형식 (`<교과>.md`)

```
## 연구 주제 요약
## 타당성
## 설계 검토
### 강점
### 개선 필요
### 치명적 오류 (있다면)
## 안전·윤리
## 선행 연구 키워드
## 다음 단계 권장
```
